# LoopNexus

A simple LoopNexus Service for Caching.

LoopNexus is built to be simple and practical, focusing on doing one thing well.

- A simple LoopNexus Service for Caching

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/LoopNexus.git`
2. `cd LoopNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

LoopNexus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
